# Service Level and Continuity Obligations

The Service Level Objectives (SLOs) and continuity obligations each Public Goods Award project
commits to. Each project sets its own, once, and they stay in place from quarter to quarter. Changes
are made by pull request, so each page's history shows what was committed and when.

See
[Service Level and Continuity Obligations](pg-award/proposer-instructions.md#service-level-and-continuity-obligations)
in the proposer instructions for how to submit or change them.
